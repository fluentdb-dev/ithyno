## Why

The tmux startup string generated by `ptyStartup()` uses POSIX shell syntax
(`2>/dev/null`, `grep -qw`, `exec`, `|| true`) that is incompatible with
PowerShell, the PTY shell on Windows. As a result, env vars (`ITHYNO_PORT`,
`ITHYNO_BASE`, `ITHYNO_SESSION_TOKEN`) are never passed to tmux when running
on Windows, and the manager agent cannot connect to the dashboard.

## What Changes

- `ptyStartup()` detects `process.platform === 'win32'` and generates a
  PowerShell-native startup string that calls psmux (Windows-native tmux port)
  directly with `-e VAR=$env:VAR` syntax.
- Non-Windows behavior is unchanged.

## Capabilities

- Modified: `embedded-terminal`
